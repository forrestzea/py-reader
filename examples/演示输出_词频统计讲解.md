## 第一段：【逐段解释】

### ▍第 1 段：导入工具包

```python
import re
from collections import Counter
```

- 白话解释：这两行是在"借工具"。Python 自带很多现成工具箱，用之前要先说一句"我要用"。
- `import re`：借来"正则表达式"工具箱——正则表达式是一种用文字规则查找内容的方法，后面用它从文章里把单词挑出来。
- `from collections import Counter`：从 collections 工具箱里单独取出 `Counter`（计数器）——一个专门用来数"每个东西出现了几次"的工具。
- 生活类比：做菜前先把要用到的调料从柜子里拿到灶台上。

---

### ▍第 2 段：函数 read_file —— 读文件内容

```python
def read_file(file_path):
    """读取文本文件内容，返回字符串"""
    with open(file_path, "r", encoding="utf-8") as f:
        text = f.read()
    return text
```

- 白话解释：这是一个"函数"——把一段功能打包起来，起个名字，以后喊名字就能用，像菜谱：写一次，以后照着做多少次都行。
- `def read_file(file_path):`：定义一个叫 read_file（读文件）的函数，括号里的 file_path 是"参数"——调用时要递给它一个文件路径，告诉它读哪个文件。
- `with open(...)`：打开文件。`"r"` 表示只读，`encoding="utf-8"` 表示按 UTF-8 编码读取（防止中文乱码）。with 写法的好处是：读完自动帮你关文件，不用自己操心。
- `text = f.read()`：把文件全部内容读出来，存进变量 text。变量——就是给数据起个名字，方便后面反复使用。
- `return text`：把读到的内容"交还"给调用它的人。

---

### ▍第 3 段：函数 split_words —— 把文章切成单词

```python
def split_words(text):
    """把文本切分成单词列表（只保留字母单词，统一转小写）"""
    words = re.findall(r"[a-zA-Z]+", text.lower())
    return words
```

- `text.lower()`：把整篇文章的字母全部转成小写。这样 "Python" 和 "python" 会被当成同一个词统计。
- `re.findall(r"[a-zA-Z]+", ...)`：用正则表达式 `[a-zA-Z]+`（意思是"一个或多个连续英文字母"）把文章里所有单词挑出来，组成一个列表。标点、数字、空格自动被忽略。
- 常见疑惑：`[a-zA-Z]+` 看起来像天书？它只是"查找规则"：a-z 是小写字母、A-Z 是大写字母、+ 表示"连续多个"。初学者先记住作用即可，规则细节以后再学。

### ▍第 4 段：函数 count_words —— 数数

```python
def count_words(words):
    """统计每个单词出现的次数"""
    counter = Counter(words)
    return counter
```

- 白话解释：把单词列表交给 Counter，它自动数出每个单词出现几次。结果像一个"词典"：单词 → 次数。
- 这一行体现了 Python 的风格：常见需求都有现成工具，一行顶别人十行。

---

### ▍第 5 段：函数 show_top —— 打印排行榜

```python
def show_top(counter, top_n=5):
    """打印出现次数最多的前 top_n 个单词"""
    print("===== 单词出现次数排行 =====")
    for word, count in counter.most_common(top_n):
        print(f"{word:<15} {count} 次")
```

- `top_n=5`：这是"带默认值的参数"——调用时不给数字就默认显示前 5 名，给了就按给的来。
- `counter.most_common(top_n)`：取出出现次数最多的前几个（单词, 次数）组合。
- `for ... in ...`：循环——把排行榜里的每一项挨个处理一遍，像点名：念到一个，处理一个。
- `print(f"...")`：f-string 格式化输出，把单词和次数填进字符串里打印到屏幕。`{word:<15}` 表示单词占 15 个字符宽度、左对齐，让输出整齐好看。

### ▍第 6 段：main 函数 + 程序入口

```python
def main():
    file_path = "article.txt"
    text = read_file(file_path)
    words = split_words(text)
    counter = count_words(words)
    show_top(counter)


if __name__ == "__main__":
    main()
```

- `main()` 是"总指挥"：把前面四个功能按顺序串起来——读文件 → 切单词 → 数数 → 打印。注意：这里文件名叫 `article.txt`，要和本程序放在同一个文件夹里。
- 常见疑惑 ⭐：`if __name__ == "__main__":` 是 Python 最著名的"咒语"。意思是：**只有当这个文件被直接运行时，才执行 main()**；如果这个文件被别的程序"借用"（import），就不自动执行。这是 Python 程序的惯例入口写法，先背下来，原理以后会懂。

## 第二段：【整体运行逻辑与流程】

**一句话概括**：这个程序读一篇文章，统计每个英文单词出现几次，打印出现最多的前 5 名。

**谁调用谁**：

```
程序启动
  └── main()                    ← 总指挥
        ├── read_file()         ← 读 article.txt，得到整篇文章
        ├── split_words()       ← 把文章切成单词列表
        ├── count_words()       ← 统计每个单词出现次数
        └── show_top()          ← 打印前 5 名排行榜
```

**数据怎么流动**：

```
article.txt（磁盘上的文件）
   → text（一整段文字）
   → words（单词列表，如 ["python", "is", "a", ...]）
   → counter（统计结果，如 {"python": 5, "is": 3, ...}）
   → 屏幕上的排行榜
```

**执行顺序**：电脑从文件最底部 `if __name__ == "__main__":` 开始执行 → 调用 main() → main 里四行按从上到下依次执行 → 程序结束。（上面的函数定义只是"备好菜谱"，被调用时才真正执行。）

## 第三段：【预期运行结果】

**运行前提**：本文件旁边要有一个 `article.txt`（英文文本），Python 版本 3.x，不需要安装任何第三方库。

**实际运行效果**（已用附带的 article.txt 真实运行验证）：

```
===== 单词出现次数排行 =====
python          5 次
is              3 次
learning        3 次
language        2 次
easy            2 次
```

**常见失败情况**：

1. `FileNotFoundError: article.txt` —— 旁边没有 article.txt 这个文件，或你在别的文件夹里运行了程序
2. 中文统计不出来 —— 正则 `[a-zA-Z]+` 只认英文字母，统计中文需要换方法（如 jieba 分词）
3. 终端中文显示为乱码 —— Windows 终端编码问题，不影响程序逻辑本身
