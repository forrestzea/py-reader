源代码

"""词频统计小工具"""
import re
from collections import Counter
def read_file(file_path):
    with open(file_path, "r", encoding="utf-8") as f:
        text = f.read()
    return text
def split_words(text):
    words = re.findall(r"[a-zA-Z]+", text.lower())
    return words
def count_words(words):
    counter = Counter(words)
    return counter
def show_top(counter, top_n=5):
    print("===== 单词出现次数排行 =====")
    for word, count in counter.most_common(top_n):
        print(f"{word:<15} {count} 次")
def main():
    file_path = "article.txt"
    text = read_file(file_path)
    words = split_words(text)
    counter = count_words(words)
    show_top(counter)

if __name__ == "__main__":
    main()

逐段解释（点击左侧代码可定位）

① 导入工具包 做菜前先把调料拿到灶台上。import（导入）就是"借工具"：re 是正则表达式工具箱（按规则查找文字），Counter 是专门数"每个东西出现几次"的计数器。
② read_file：读文件 函数——把一段功能打包起个名字，像菜谱，写一次用无数次。with open 打开文件并自动关闭；"r" 表示只读；utf-8 防止中文乱码；return 把读到的内容交还出去。
③ split_words：切单词 text.lower() 把字母全转小写（让 Python 和 python 算同一个词）；正则 [a-zA-Z]+ 表示"连续英文字母"，把所有单词挑出来组成列表，标点数字自动忽略。
④ count_words：数数 把单词列表交给 Counter，自动数出每个词出现几次。结果像词典：单词 → 次数。一行顶别人十行，这就是 Python 的风格。
⑤ show_top：打印排行榜 top_n=5 是带默认值的参数（不传就显示前5名）；for 循环把排行榜逐项处理，像点名；f-string 把单词和次数填进字符串，<15 让输出对齐整齐。
⑥ main：总指挥 + 程序入口 把四个功能按顺序串起来：读文件→切单词→数数→打印。
⭐ 常见疑惑：if __name__ == "__main__" 意思是"只有直接运行本文件时才执行 main()"，被别的程序借用时不执行。先背下来，原理以后懂。

📌 一句话概括

读一篇文章，统计每个英文单词出现几次，打印前 5 名。

🔗 谁调用谁

main()
 ├─ read_file()    读 article.txt
 ├─ split_words()  切成单词列表
 ├─ count_words()  统计次数
 └─ show_top()     打印排行榜

🌊 数据怎么流

article.txt
 → 整段文字
 → 单词列表
 → {单词: 次数}
 → 屏幕排行榜
