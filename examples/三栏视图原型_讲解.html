第 1 行告诉浏览器'这是一个现代网页';第 2 行是整棵'大树'的根——页面上所有东西都是它的子孙。

📋 逐行拆解

  • 第 1 行 <!DOCTYPE html> —— 文档类型声明:告诉浏览器"请按 HTML5 现代标准解读这个文件"。
  • 第 2 行 <html lang="zh-CN"> —— 整个网页的根标签;lang="zh-CN" 表示页面语言是中文(有助于浏览器和搜索引擎正确处理)。

📖 术语与语法(第一次出现,只讲一次)

◆ 标签(成对盒子)
语法:<标签名>内容</标签名>
是什么:HTML 的基本单位:一个盒子。开头标签告诉浏览器'盒子里是什么',结尾标签(带斜杠)表示盒子结束。
类比:快递盒:面单写内容,盒子装东西,封箱表示结束。
本文件中:本文件所有内容都装在标签盒子里,如 html、head、body、div。
◆ 属性
语法:<标签名 属性名="值">
是什么:写在开始标签里、给标签补充信息的'小纸条',一个标签可以带多张。
类比:快递单上的备注栏:易碎、加急、收件人……
本文件中:lang="zh-CN" 就是 html 标签的一张小纸条。
◆ DOCTYPE 声明
语法:<!DOCTYPE html>(固定写法,记住即可)
是什么:网页的第一行声明,不是标签也不是内容,只是告诉浏览器用哪套规则解读后面的代码。
类比:进门前先报'我们说普通话'——后面聊天才不跑偏。
本文件中:HTML5 的标准声明就是这一行,写错或漏写可能触发浏览器的'兼容模式',样式表现异常。

⭐ 常见疑惑

Q:DOCTYPE 为什么有个感叹号?——它是给浏览器看的特殊声明,不是成对标签,所以格式与众不同,照抄即可。

head 区是网页的'幕后档案':这里的内容不直接显示在页面上,而是设置网页的名字、编码等元信息。

📋 逐行拆解

  • 第 3 行 <head> —— head 区开始(幕后档案区)。
  • 第 4 行 <meta charset="UTF-8"> —— 设置字符编码为 UTF-8,保证中文不乱码。
  • 第 5 行 <title>...</title> —— 网页标题:显示在浏览器标签页上。

📖 术语与语法(第一次出现,只讲一次)

◆ head 区
语法:<head>...</head>
是什么:网页的'幕后档案区':编码、标题、样式表等都登记在这里;用户看不见它,浏览器开工前必读。
类比:演出前的后台:灯光、道具、节目单都在这里准备,观众只看到前台。
本文件中:本文件的 head 里装了 meta 和 title,以及下面第 6~30 行的整段样式。
◆ meta charset(字符编码)
语法:<meta charset="UTF-8">
是什么:声明这个网页的文字用 UTF-8 编码保存;不声明,中文可能显示成一堆乱码方块。
类比:约定'咱们用普通话通话',双方编码一致才不会鸡同鸭讲。
本文件中:charset 是 character set(字符集)的缩写。
◆ title(网页标题)
语法:<title>文字</title>
是什么:网页的名字,显示在浏览器标签页卡上,也是收藏时的默认名字。
类比:书本封面上的书名。
本文件中:本页标题是「词频统计.py —— 三栏讲解视图(产品原型演示)」。

📖 术语与语法(第一次出现,只讲一次)

◆ style 区与 CSS
语法:<style> CSS 规则 </style>;规则格式:选择器 { 属性: 值; }
是什么:CSS = 层叠样式表,网页的'化妆师';style 标签把化妆师请进网页。每条规则 = 选中谁 + 化什么妆。
类比:装修图纸:哪个房间(选择器)、刷什么漆(颜色)、多高多宽(尺寸)。
本文件中:第 7~29 行全是 CSS 规则,一共二十多条。
◆ 选择器与类选择器(.点开头)
语法:标签选择器:body;类选择器:.pane;后代选择器:.left h3
是什么:选择器 = 规则作用于谁。点开头的是'类名'——标签上写 class="xxx" 归到这个类,类规则就适用于它。
类比:班级点名:body 是'全体宿舍',.pane 是'所有叫 pane 的同学',.left h3 是'左班的同学里的 h3'。
本文件中:第 11 行 .pane 对应下面 class="pane left" 的 div;第 16 行 .left h3 只影响左栏的标题。
◆ flex 布局(弹性排列)
语法:display: flex; flex-direction: row/column;
是什么:CSS 的排列方式之一:让子元素像弹簧一样按方向排队,自动分配空间。row=横排,column=竖排。
类比:食堂窗口排队:纵队(column)或横队(row),大家自动站好。
本文件中:第 8 行 body 纵向排(页头在上、main 在下);第 10 行 main 横向排(三栏并排)——这是本页面最核心的布局手法。
◆ 尺寸单位(px / % / vh)
语法:width: 38%; height: 100vh; padding: 12px;
是什么:px=像素(固定大小);%=占父容器的百分比;vh=视口高度的百分之几(100vh=正好一屏高)。
类比:px 是'固定工资',% 是'按比例分家产',vh 是'占屏幕身高的几成'。
本文件中:三栏宽度用 %(跟着窗口大小缩放),body 高度用 100vh(永远正好一屏)。
◆ 颜色 #十六进制
语法:color: #fff; background: #1e1e1e;
是什么:# 开头六位十六进制数表示颜色,每两位一组:红绿蓝。#fff 是白色缩写,#1e1e1e 是深灰。
类比:调色盘上的编号,报编号就能调出同样的颜色。
本文件中:左栏 #1e1e1e 模仿了 VS Code 编辑器的经典深色。
