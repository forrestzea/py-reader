<style>
  body { display: flex; flex-direction: column; }
  main { flex: 1; display: flex; }
  .left   { width: 38%; background: #1e1e1e; }

  .right  { width: 28%; background: #fdf6e3; }

<!-- ③ 顶部标题栏 -->
<header>📄 示例代码_词频统计.py —— 打开即讲解</header>

<div class="pane left">
  <div class="codeblock" data-s="1">

  </div>

<!-- ⑤ 中栏：逐段解释面板 -->
<div class="pane middle">

    <b class="t">① 导入工具包</b>

  </div>

<div class="pane right">
  <h4>📌 一句话概括</h4>

  <h4>🖥️ 实际运行结果</h4>
  <pre class="output">python  5 次 ...</pre>
</div>
<!-- ⑦ 脚本：点击联动（核心逻辑节选） -->
<script>
  document.querySelectorAll('.codeblock').forEach(c => {
    c.onclick = () => {
      const e = document.querySelector(
        '.exp[data-s="' + c.dataset.s + '"]');
      e.classList.add('active');
      e.scrollIntoView({behavior:'smooth'});
    };
  });
</script>

逐段解释（点击左侧代码可定位）

① 文档头：告诉浏览器"我是谁" 学 HTML 先记住一句话：标签是成对的盒子，<html>...</html> 告诉浏览器"这中间是一个网页"。
· <!DOCTYPE html>：声明"这是现代网页"，固定写法，背下来即可。
· <head>：网页的"档案袋"，放设置信息，里面的内容不会显示在页面上。
· charset="UTF-8"：字符编码声明——告诉浏览器按 UTF-8 规则解读文字，少了它中文会变乱码。
· <title>：浏览器标签页上显示的名字。
生活类比：head 像快递单（写给系统看的），body 才是包裹里的东西（给人看的）。
② 样式区：控制"长什么样" <style> 里写的是 CSS——一种专门描述外观的语言：颜色、宽度、间距、边框。HTML 管结构，CSS 管装修。
· display: flex：弹性布局——让子元素像书架上并排的书一样横向排开。本页的三栏就是靠 main 里的 flex 排出来的。
· .left { width: 38% }：以 . 开头表示"按 class 名字选人"——所有 class="left" 的元素都套用这条规则。三栏宽度 38/34/28，加起来正好 100%。
· #1e1e1e 这类是颜色的十六进制写法：# 后面 6 位，两位一组分别表示红、绿、蓝的浓度。
· .active：被点击时的"高亮样式"，后面脚本会给点中的块加上它。
⭐ 常见疑惑：CSS 为什么不写在 HTML 标签里？——集中写在 style 里，改一处全页面生效，这就是"结构与样式分离"的思想。
③ 顶部标题栏 <header> 是"语义化标签"——作用和 <div> 一样是个盒子，但名字本身说明了用途（页眉），方便人和搜索引擎理解。里面就是一行标题文字。
④ 左栏：源代码面板 左栏是一个 class="pane left" 的 <div>（div = 通用盒子，网页里最常见的积木）。里面放着 6 个 codeblock 盒子，每个装一段代码。
· data-s="1"：自定义属性——标签上自己贴的便利贴，内容是编号。这是左右联动的钥匙：左边代码块贴 data-s="1"，中栏对应的解释也贴 data-s="1"，脚本靠编号把它们配成对。
· <pre>：预格式文本标签——保留代码里的换行和空格，代码显示必备。
· 代码里的彩色是靠 <span class="kw">（关键字蓝色）、class="str"（字符串橙色）等手工标记的。
注意：左栏显示的代码<和>都写成了 &lt; &gt;——这是 HTML 转义，因为浏览器会把真正的 <> 当成标签解析掉。
⑤ 中栏：逐段解释面板 结构与左栏完全对称：6 个 exp（解释）盒子，同样贴 data-s 编号，与左侧一一对应。
· 每个解释块里：<b class="t"> 是蓝色小标题，正文是大白话讲解。
· 第⑥段解释里那个黄色"⭐ 常见疑惑"框，是用 CSS 的 border-left（左边框）+ 背景色画出来的——你现在看到的本页中栏也是完全一样的做法。
发现了吗？这个文件本身就是"用三栏讲解页讲解三栏讲解页"——你现在点的每一块，讲解的都是你正在看的这个东西。
⑥ 右栏：整体逻辑面板 静态内容区：概括、调用关系、数据流、运行结果、常见报错，全部写死在 HTML 里。
· 米色背景（#fdf6e3）+ 棕色小标题，视觉上和左中两栏区分开。
· 运行结果用 class="output" 的 pre 显示：深色底、青绿色字，模拟终端的样子。
这一栏没有任何交互，纯展示——所以代码最简单，全是文字和排版。
⑦ 脚本区：让页面"能点" <script> 里写的是 JavaScript——网页的"动作语言"。HTML 是骨架、CSS 是皮肤、JS 是肌肉。
这段脚本做的事，翻译成大白话就三步：
1. querySelectorAll('.codeblock')：把页面上所有代码块找出来，排成一个名单
2. 给每个代码块挂一个"点击响应"（onclick）：你点它，它就执行后面大括号里的事
3. 点中时：读出这个块的 data-s 编号 → 用编号找到中栏同款编号的解释块 → 给它加上 active 高亮样式 → scrollIntoView 滚动到它
（文件后半还有一段几乎相同的代码，方向反过来：点解释找代码。）
⭐ 常见疑惑：=＞ 是什么？——"箭头函数"，就是"点中后要执行的动作"的简写。先理解作用，写法细节以后再抠。

整体逻辑 · 结构 · 效果

📌 一句话概括

这是一个"代码讲解页"：用浏览器把一份 Python 代码和它的解释三栏并排展示，点击任意一边可以定位对照另一边。

🧱 网页的三层结构

HTML（骨架）
 ├─ head   设置区：编码、标题
 └─ body   内容区
     ├─ header  顶部标题栏
     └─ main    三栏（左/中/右）
CSS（皮肤）  → 决定三栏宽度、配色、高亮样式
JS（肌肉）   → 实现"点击互找"的联动

🖱️ 交互怎么发生

你点击左侧代码块
 → JS 读出它的 data-s 编号
 → 按编号找到中栏对应解释
 → 两边同时加高亮
 → 解释块滚动到视野中间

🖥️ 浏览器里看到的效果

顶部：深色标题栏
左栏：黑底彩色代码（6 段）
中栏：白底解释（6 块）
右栏：米色逻辑总结
点任意代码块 → 对应解释
蓝框高亮并自动滚动到位

⚠️ 常见问题

  • 中文乱码 → 文件须以 UTF-8 保存（本文件已是）
  • 点击无反应 → 浏览器禁用了 JavaScript
  • 布局挤变形 → 窗口太窄，三栏按百分比分配宽度
